# Inwentaryzator – kolektor spisu z natury

Kolektor danych do spisu z natury środków trwałych w przeglądarce (Sigma). Strona: `index.html` (jeden plik, bez serwera i bibliotek).

**Adres:** https://trekpio.github.io/inwentaryzator/ – otwierać w Chrome; skanowanie kamerą działa tylko z adresu https (nie z pliku na telefonie).

- Skanowanie kamerą telefonu (Chrome na Androidzie; iPhone / iPad – czytnik zastępczy barcode-detector/ZXing pobierany z CDN), skanerem w trybie klawiatury albo wpis ręczny.
- Dane spisu są zapisywane wyłącznie w pamięci przeglądarki na urządzeniu – strona niczego nie wysyła.
- Eksport CSV / XML / JSON do importu w enova365 (cecha DaneSpisu).

Aktualizacja: podmień `index.html` na nową wersję `inwentaryzator.html` (zmiana nazwy pliku na `index.html`).
